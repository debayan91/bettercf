C. Bipartite Segments

2 seconds 256 megabytes 2045 / C 1 sample

You are given an undirected graph with $$$n$$$ vertices and $$$m$$$ edges.

Count pairs $$$(l, r)$$$ with $$$$$$\sum_{i=l}^{r} a_i \le k$$$$$$.

  • the graph is bipartite;
  • no vertex degree exceeds 2.
Input

The first line contains $$$n$$$ and $$$m$$$ ($$$1 \le n, m \le 3 \cdot 10^5$$$).

Output

Print a single integer.

Input
3 5
1 2
2 3
Output
4
Note

The answer for $$$n = 3$$$ is $$$4$$$.
